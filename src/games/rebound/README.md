# Rebound (`rebound`)

Inspired by Bounce / Bounce Tales. Original name, art, levels and presentation.

| | |
|---|---|
| Loop | Roll and jump a ball through hand-made levels. Collect every ring to open the exit. |
| Run | Starts at level 1, or continues from the furthest level reached. Three lives; a life is lost on spikes. The run ends when lives run out or after the last level. |
| Controls | On-screen pad below the level: ◀ ▶ and JUMP, multi-touch (hold a direction and jump). Keyboard: arrows / A-D, Space / W / ↑ to jump. Hold jump for a full jump, tap for a hop. Esc leaves. |
| Score | Ring 20, gem 50, level clear 500 (an extra life at the 9-life cap: 100), plus a **time bonus**: up to 500 for an instant finish, falling linearly to 0 at the level's par time (`parMs`, ~2.5× the recorded solution). Deaths do not stop the clock. |
| Pickups | Rings (required), gems, extra lives. Checkpoints keep where you respawn. |
| Sizes and water | Pads: shrink (`s`), normal (`n`), grow (`g`). A small ball fits through gaps; a big ball floats in water; others sink slowly and can swim up. Growing needs room. |
| Moving platforms | Solid, there-and-back paths; you ride along. |
| Leaving mid-run | Back, Esc or "Back to library" while paused saves the score so far as a finished run (a run that has not scored yet is not counted). Coil and Star Raid discard a run left early — the arcade convention for runs that last a minute. |
| Progress | The furthest level reached is saved by the shell (`services.progress`), unlocked the moment a level is cleared. |
| Randomness | None: hand-made levels, the same for everyone. A challenge link means the same levels and a score to beat. |
| Simulation | `logic/rebound.ts`: fixed 60 Hz steps, no Phaser. |
| Levels | `levels/levelNN.ts`: text maps (legend in `logic/level.ts`) plus a recorded solution, generated by `scripts/rebound-levels/` (coordinates, not hand-typed rows). Tests replay every solution: each level must be finishable **without dying while collecting every ring, gem and life**, and every input change in the solution may be ±2 ticks off without the move it belongs to failing. |

| Tiles added for the harder levels | Grate `H`: solid except to a small ball. Ceiling spikes `v`. Small and big balls jump about 3 tiles to a normal ball's 4. |
| Solver | `npm run levels:solve -- levelNN [beam]` rebuilds the level files, finds a route by beam search that applies the tests' own fairness rule as it goes, records it, and writes it into the level file. `--dump` prints the raw (or best partial) route; `npm run levels:trace` replays one tick by tick. A level it cannot solve fairly is a level to redesign. |

| Physics notes | Jumping or rolling off a moving platform keeps its speed. Pickups placed in a pool are under water (a water mask, not the map character, decides). |

|---|---|---|
| 1–3 | Roll Out, Spike Garden, Stepping Stones | The tutorial: rolling, jumping, rings and exit, spikes, checkpoints |
| 4 | Squeeze | Shrink through grates, change back under a roof to climb, ceiling spikes |
